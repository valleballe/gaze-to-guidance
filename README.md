# From Gaze to Guidance: Interpreting and Adapting to Users' Cognitive Needs with Multimodal Gaze-Aware AI Assistants.


This repository will contain the code and documentation for "From Gaze to Guidance: Interpreting and Adapting to Users' Cognitive Needs with Multimodal Gaze-Aware AI Assistants", to be published at ACM UIST 2026.

The code is currently being cleaned, documented, and prepared for public release. We expect to release the initial version soon.

The release will include implementation code, setup instructions, examples, study data and evaluation materials where permitted.

Please watch this repository for updates.
